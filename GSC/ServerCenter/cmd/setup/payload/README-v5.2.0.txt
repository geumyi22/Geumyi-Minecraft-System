Geumyi Server Center 5.2.0 · Windows x64

GSC Client 왼쪽 메뉴 맨 아래의 ‘위험 작업’에서 GMS 운영 모드를 엽니다.
Host 시작 유형과 Client 로그인 자동 실행 상태를 확인하고,
‘운영 모드 관리자 열기’를 눌러 상세 검사를 진행합니다.
독립 실행이 필요하면 GMS_OperatingMode_v3.0.1.exe를 직접 엽니다.
도구는 현재 PC의 GSC Host·Client·서버 자동 시작 경로를 검사합니다.
원격 Host를 관리하는 PC라면 서버 PC의 자동 시작 상태는 그 PC에서 확인하세요.

수동 운영을 시작할 때
1. 일반 권한으로 검사 결과와 적용할 항목을 확인합니다.
2. 관리자 권한과 변경 내용을 확인한 후 수동 모드를 적용합니다.
3. 접속 중인 사용자가 없는 시간에 기존 종료 절차로 서버를 정상 종료합니다.
4. 재부팅 후 다시 검사하고, 필요할 때 Host를 수동으로 시작합니다.
5. 상시 운영으로 되돌릴 때는 원래 설정을 저장한 PC에서 복원을 선택합니다.

기존 서버 PC의 Setup 업그레이드
운영 서버의 월드·플레이어와 설정을 먼저 백업하세요.
기존 Host 업그레이드는 4.5.1, 5.0.0, 5.1.0, 5.1.1 또는 5.2.0의
실행 중인 서비스와 API 세대 4를 확인합니다. 저장한 역할에 버전이 있으면
실행 버전과 일치해야 합니다. 기존 복원 기록에 Setup이 변경할 Host·Client
시작 항목이 있거나 전환이 중단됐으면 변경 전에 Setup이 보류됩니다.
점검 시간에 관리자로 ‘중단된 작업 복구’ 또는 ‘기존 모드 복원’을 완료하세요.
기존 Host가 여전히 중지 상태이면 수동 시작하여 정상 상태를 확인하세요.

대화형 Setup의 서버 역할은 자동(지연 시작) Host 서비스를 다시 등록하고,
Client 역할은 트레이 자동 실행 선택에 따라 로그인 시작 값을 설정합니다.
수동 운영 중이었다면 설치 후 재부팅 전에 관리자로 다시 검사하고 재적용하세요.
실제 서버의 자동 시작 전환·재부팅·복원은 운영자가 별도로 검증합니다.
