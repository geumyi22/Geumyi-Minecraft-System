Geumyi Server Center 5.1.0 — 개인용 서버 관리 개발본

Host, Client, Setup의 제품 버전은 5.1.0입니다. GSCM과 기존 연동
플러그인의 버전은 별도로 유지하며, 기존 v4 관리 API와 호환됩니다.
공개된 GSC 5.0.0 릴리스 파일·서명·승인 기록은 이 개발본과 구분합니다.

새 기능:
- Paper, Spigot, Purpur, Vanilla, Fabric, Forge, NeoForge 자동 설치
- 새 Velocity 생성 및 GSC 소유 프로세스의 시작·정상 종료·재시작
- 호환 Java 및 필요한 Spigot 빌드 도구 자동 준비
- 기존 서버 폴더 가져오기, 로그·콘솔, 파일 삭제 없는 등록 해제

기존 Velocity 3개의 실행 주체는 Windows 작업 스케줄러로 유지합니다.
기존 프록시 제어 연결은 중지 상태에서 별도로 준비해야 합니다.
새 GSC 소유 Velocity와 기존 예약 작업의 소유권을 혼동하지 마세요.
기존 서버·월드·플레이어 데이터의 자동 변환이나 소유권 이관은 하지 않습니다.

실제 실행 검사는 별도 폴더의 개인용 Host/Client 패키지로 수행했습니다.
이 버전 번호와 Setup 빌드 경로 정리는 Windows Setup 설치·역할 전환·
운영 업데이트의 실제 검증이나 배포 완료를 의미하지 않습니다.
기존 마이그레이션 보호·설정 백업·롤백 처리는 유지합니다.

서명된 업데이트 메타데이터 검증과 Windows Authenticode 서명은 별개입니다.
이 개발본으로 공개 Stable 파일이나 업데이트 서명을 교체하지 않았습니다.
설정·월드·인증 토큰·개인 키를 공개 저장소에 올리지 마세요.
