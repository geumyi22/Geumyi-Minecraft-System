v4의 핵심
🖥
서버 호스트 백그라운드 관리야생/놀이터 자동 시작·복구·RCON
🤖

▣

⚙
통합 설정서버 경로·자동복구·원격 연결을 앱에서 설정
v4.2.3은 역할을 기억합니다. 서버 PC ↔ 관리 PC ↔ 둘 다로 바꾸면 필요한 구성요소를 자동 추가/제거하고, 전용 서버 Windows 설정도 안전하게 적용/원복합니다. 기존 Minecraft 월드, plugins, server.properties는 삭제하지 않습니다.

설치 유형 선택

이 PC의 역할에 맞는 구성을 선택하세요.
역할별 자동 설정
🛡
보안 설정은 유지Defender와 Windows Update 자체는 끄지 않고, RCON/GDS 내부 포트는 외부에 열지 않습니다.

서버 / 연결 구성

서버 PC의 실제 서버 폴더를 확인합니다.
기존 ProgramData의 server_path.txt / launch.cmd 설정을 자동 감지합니다. 서버 PC에서 OneDrive 경로가 감지되면 설치 후 전용 서버 폴더로 이전 권장을 안내합니다.
LAN 또는 Tailscale 주소를 권장합니다. RCON 포트는 외부에 직접 공개하지 않습니다.

설치 준비 완료

설치 내용을 확인한 뒤 설치를 시작하세요.
역할 전환 시 기존 구성요소를 자동 정리합니다. 서버 → 관리 PC 전환은 Minecraft 서버를 먼저 저장·정상 종료하며, 강제 Java 종료는 하지 않습니다. 서버 데이터 자체는 건드리지 않습니다.

설치 진행

백그라운드에서 설치 중입니다. 화면은 계속 응답하도록 설계되어 있습니다.
준비 중...
