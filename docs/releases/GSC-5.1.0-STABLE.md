# GSC 5.1.0 — 개인용 Stable

**출시 범위:** 운영자가 2026-11-15에 요청한 개인용 GSC Windows Host·Client·Setup 릴리스입니다. 정식 공개 5.0.0의 코드를 단순히 재명명한 파일이 아니라, 5.1.0 소스로 정확한 Windows CI를 거쳐 새로 빌드한 산출물이어야 합니다.

이 배포는 **개인용으로 범위를 한정해 승인한 Stable**입니다. 프로젝트 전체의 정식 운영 보안 게이트나 모든 Minecraft/모바일 E2E 완료 선언은 아닙니다.

## 무엇이 달라졌나요?

- **서버 생성/관리:** Paper, Spigot, Purpur, Vanilla, Fabric, Forge, NeoForge 7종의 공식 서버 파일 준비, 자동 Java·설치 도구 준비, 기존 서버 가져오기, 콘솔·로그와 시작·정상 종료·재시작.
- **프록시 관리:** 별도로 새로 만든 Velocity를 GSC가 직접 시작·정상 종료·재시작하는 기능. 기존 Windows 작업 스케줄러가 소유한 야생·놀이터·기타 Velocity 3개는 실행 주체를 변경하지 않으며, 제어를 연결하려면 접속자 없는 안전한 시간에 기존 방식으로 **한 번 정상 종료**한 뒤 오프라인에서 인증 제어 플러그인을 준비해야 합니다. **기존 프록시를 실행 중에 바로 종료하는 기능이 아닙니다.**
- **데이터 보호:** 기존 월드·플레이어 데이터·백업·서버 설정을 설치/등록 과정에서 자동 삭제·변환하지 않습니다. 중지 상태 설정 편집 및 파일 삭제 없는 등록 해제를 지원합니다. 강제 종료는 자동 대체 수단이 아닙니다.
- **5.0 유지보수 보존:** 외부 Geyser Staging 시간 제한/오류 보고, NetherNet 상태/롤백 검증, Windows 온라인 백업의 `session.lock` 문제와 브라우저 요청 보호 등이 유지보수 기반에서 포함됩니다.

## 검증한 범위와 한계

- **이 릴리스는 정확한 빌드 커밋의 Windows System CI가 모두 성공하고, 서명된 Draft의 모든 자산·출처·해시가 재검증될 때만 게시합니다.** 다운로드 파일의 SHA-256과 `deployment-stable.json` Ed25519 서명은 검증할 수 있도록 첨부합니다. 서명은 **Windows Authenticode 코드 서명이 아닙니다.**
- 개발 중 별도 테스트 폴더에서 서버 7종과 새 Velocity의 자동 설치·기동, 자동 클라이언트의 로컬 접속/월드 진입, 콘솔, 정상 종료·재시작/재접속, 파일/월드 저장 테스트가 기록됐습니다. 해당 클라이언트는 **실제 Microsoft 계정으로 로그인한 사람의 플레이가 아닙니다.**
- 별도 Velocity 제어 플러그인 테스트 환경에서는 토큰 인증, PID/시작 시각 일치, 정상 종료/재실행과 무인증·브라우저 요청 거부를 확인했습니다. **운영 중인 Windows Scheduler 소유 프록시 3개의 실제 전환·종료는 수행하지 않았습니다.**
- **미실행/별도 승인:** 운영 PC의 5.0 → 5.1 실제 설치·롤백, Windows 전체 그래픽 UI 수동 클릭, 실제 Microsoft 계정/Java·Bedrock 장시간 멀티플레이, 외부망·원격 GSCM 인증, 새로운 버전·모드팩 전체 조합, 라이브 월드 복원은 이 릴리스만으로 PASS로 주장하지 않습니다.

## 설치 및 업데이트 주의

**현재 정상 작동하는 GSC 5.0.0 운영 PC에 바로 덮어쓰지 마세요.** 기존 Host·Client·설정·백업과 Minecraft JVM·월드의 경로를 먼저 확인하고 별도로 백업한 뒤, 안전한 유지보수 시간에 설치·복원 가능성을 검증하세요. 기존 프로그램 버전·실행 파일이 일치하지 않으면 Setup 보호 장치를 해제하지 말고 정확한 마이그레이션 절차를 사용합니다.

개인용 기능을 시험하는 가장 안전한 방법은 [독립된 데이터 폴더로 실행하는 사용 안내](GSC-5.1.0.md)의 개발/개인용 실행 경로입니다. 새 테스트 서버와 실제 기존 서버를 같은 디렉터리에 혼합하거나 기존 Scheduler 프록시 작업 정의를 강제로 교체하지 마세요.

공개 GSC 5.0.0 릴리스는 별도 태그로 그대로 보존됩니다. GSCM 및 Minecraft 월드/실서버 플러그인과 서버 데이터는 5.1.0 Windows GSC 릴리스 자산에 포함되지 않습니다.
