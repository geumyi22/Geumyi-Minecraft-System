# GSC 5.1.0 개인용 개발본 검증 기록

작성 기준: 2026-11-15. 소스 기준 `77647c6`, 개발 브랜치 `feature/personal-server-manager`.

**자동 설치 구현은 8종입니다. 설치 성공, 실제 기동, 게임 접속, 운영 배포는 서로 다른 상태로 기록합니다.** 8종 API 자동 설치와 아래 실제 실행 검사를 통과했고, 최종 패키지의 재검사도 마쳤습니다.

## 구현 범위

- **서버** 메뉴에서 Paper·Spigot·Purpur·Vanilla·Fabric·Forge·NeoForge의 새 자동 설치와 기존 폴더 가져오기.
- **프록시** 메뉴에서 새 Velocity 생성·직접 실행, 기존 Scheduler 소유 Velocity 3개 찾기·등록·제어 연결 준비.
- 종류·버전·이름과 사용자 EULA 동의 중심의 생성 화면. 폴더·Java·메모리·포트는 고급 설정으로 분리하고 기본값 자동 준비.
- 호환 Java 탐색 및 공식 Temurin 전용 캐시 준비. Spigot BuildTools와 필요할 때 공식 PortableGit 자동 준비. 시스템 Java·Git 환경 설정 유지.
- 새 게임 서버의 프록시 연결 선택 시 loopback 바인딩·offline 설정을 새 파일에만 기록. 새 Velocity 생성 화면에서 해당 서버 추천.
- 상태·로그·콘솔 명령, 시작·정상 종료·재시작, 중지 상태 설정 편집, 파일 삭제 없는 등록 해제.
- 기존 서버 폴더·포트 충돌 방지, 동시 작업 제한, 실제 종료 후 재시작, 이전 Host 프로세스 기록 확인을 통한 중복 실행 방지.
- 기존 GSC Paper 연동 기능과 별도 `instances.json` 유지. 개인용 패키지는 별도 `data`와 빈 목록으로 시작.

## 검사 중 발견한 문제와 해결

- **Purpur 다운로드 시간 초과:** 긴 단일 전송이 멈추는 문제를 HTTP/1.1의 1MB 구간 다운로드로 보완했습니다. 수정 후 자동 설치와 실제 실행 검사를 통과했습니다.
- **시작 완료 표시가 너무 빠름:** 서버 포트가 먼저 열린 Forge에서 초기 접속이 거절됐습니다. 모든 새 관리 서버가 Minecraft 상태 응답을 받은 뒤 실행 중으로 표시하도록 수정하고 재검사했습니다.
- **한글 로그 깨짐:** Windows Java의 출력 인코딩과 화면의 UTF-8 해석이 달랐습니다. 직접 실행하는 Java와 설치 프로그램의 출력을 UTF-8로 맞추고 실제 한글 출력 및 관련 테스트를 확인했습니다.

NeoForge 초기 접속 검사의 ping/pong 응답 누락은 자동 검사 클라이언트의 문제였습니다. 클라이언트의 응답 처리를 보완한 뒤 월드 진입·재접속 검사를 통과했으며, 서버 자체의 결함으로 기록하지 않았습니다.

## 남은 확인과 적용 상태

- 실제 Microsoft 계정 인증, 외부 네트워크를 통한 접속, 사용자 게임 화면과 UI 클릭·화면 크기별 시각 확인.
- 운영 Velocity 최초 제어 연결, 기존 예약 작업 실행, 실제 Java·Bedrock 접속. 이번 개발 확인에서는 운영 작업을 실행하지 않았습니다.
- 모드팩·추가 플러그인 호환성, 여러 실제 플레이어, 장시간 플레이·부하·장애 복구.
- 새 프록시의 기본 전달 방식은 `none`입니다. 원래 UUID·IP 전달과 기존 월드의 UUID 전환은 구현·검증 완료 범위가 아닙니다.

기존 Paper 서버 4개와 월드·플레이어 데이터, 기존 Velocity 작업 3개, 운영 GSC 설정은 변경하지 않았습니다. 실제 운영 프로세스 종료·운영 배포는 수행하지 않았습니다. 새 테스트 서버만 별도 폴더에서 실행했습니다.

검사별 요약은 [GSC-5.1.0-verification.json](GSC-5.1.0-verification.json)을 참고하세요. 소스 기준은 `77647c6`이며, 변경 패치는 최종 패키지에 함께 제공합니다.

## 5.1.0 버전 확정 후 확인

Host·Client·Setup 소스와 화면 표시, 빌드 파일명·CI 제품 버전 정보를 5.1.0으로 맞췄습니다. Host·Client를 다시 빌드하고 전체 Go 테스트와 go vet를 통과했습니다. 새 빈 설정으로 실제 실행한 Host health/release API, Client 설정 API와 제공되는 대시보드 HTML에서 5.1.0 표시를 확인하고 확인용 프로세스를 종료했습니다.

위 8종 서버 설치·접속 기록은 기능 구현 검증 기록입니다. 버전 표기 변경 후 모든 서버 설치·게임 접속을 다시 반복한 것은 아닙니다. Setup 실제 설치와 운영 전환은 미검증입니다.

공개 전 검토에서 조회 전용 실행과 개인용 실행 옵션을 함께 지정할 때의 초기화 우선순위를 수정했습니다. 새 회귀 검사는 수정 전 파일 변경을 재현했고, 수정 후 조회 전용 상태를 유지함을 확인했습니다. 최종 전체 테스트·정적 검사·Host/Client 재빌드도 통과했습니다.
