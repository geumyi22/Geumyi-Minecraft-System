# GSC 5.0.0 — 개인용 Stable

2026-11-08(한국 시간)의 운영자 요청에 따른 개인용 Stable입니다. PR #60과 #61의 누적 변경을 포함하며 공개 `5.0.0-beta.1`과 동일한 바이너리가 아닙니다. GSCM, Minecraft 서버, 플러그인, 월드는 이 GSC 전용 릴리스에 포함하거나 교체하지 않습니다.

## 검증과 수락 범위

- **운영자 확인(2026-11-07):** 격리 Windows 11 VM에서 beta CI 산출물 설치·해시, Host/Client, API 인증 401/401/200, Windows 재부팅, 공식 제거·데이터 보존, 체크포인트 복원을 확인했습니다. 새 Stable 바이너리의 실행 결과를 뜻하지 않습니다.
- **운영자 수락(2026-11-08):** 전체 실환경 QA 완료를 주장하지 않는 개인용 Stable 게시와 데이터 보존을 전제로 한 PC 마이그레이션을 요청했습니다.
- **자동 검사:** 정확한 Stable 후보 커밋의 Windows CI·산출물 해시·Ed25519 deployment 서명 결과는 해당 GitHub Actions 실행과 함께 게시합니다. 아직 실행하지 않은 항목은 PASS로 기록하지 않습니다.
- **미실행:** 새 버전의 실제 Minecraft 플레이·월드 복원, 모바일·원격 접속 전체, 장시간 실행, 모든 백엔드 포트의 실환경 보안 검증.
- **미해결:** 일부 Windows TCP 조회에서 LISTEN 상태가 누락되지만 API와 연결은 정상입니다. 별도 제어 리스너에서도 재현됐으며 Windows/드라이버/조회 경로 중 정확한 원인은 확정되지 않았습니다.

전체 프로젝트용 `FINAL-RELEASE-GATES.json`의 실환경 게이트는 그대로 유지합니다. 이 릴리스는 그 게이트 전체를 PASS로 선언하지 않습니다. 세부 상태는 `deploy/gsc-5.0.0-personal-acceptance.json`에 구분합니다.

## 설치와 업데이트

업데이트 창은 GitHub의 Stable 배지 대신 기존에 신뢰한 Ed25519 공개키로 `deployment-stable.json`과 `.sig`를 검증합니다. Stable 채널 설정, 올바른 기존 공개키, 서명된 GSC 산출물의 SHA-256 및 크기가 모두 일치해야 합니다. deployment 서명은 Windows Authenticode 코드 서명과 다릅니다.

기존 4.5.2 Canary 및 저장/실행 버전이 다른 설치는 일반 Setup의 보호장치가 계속 차단합니다. 해당 PC는 설정·등록정보·실행 파일·서비스 경로를 백업하고 별도의 제한된 이전 절차를 사용해야 합니다. 실행 중인 Minecraft JVM·외부 Velocity 소유권·스케줄·방화벽·월드는 임의로 초기화하지 않습니다.

실제 PC 설치와 업데이트 화면 확인은 별도 실행 기록으로 보고합니다. 이 문서 또는 Release 게시만으로 PC 설치 완료를 의미하지 않습니다.
