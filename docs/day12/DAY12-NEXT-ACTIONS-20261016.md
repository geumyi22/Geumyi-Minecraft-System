## 중요 세부 안전 기준

1. **OneDrive 원본과 OneDrive의 새 백업은 서로 다른 계정/장치 장애에 대한 독립 사본이 아님.** Google Drive 쪽에서 독립적으로 재다운로드 및 복원이 가능한지 검증하는 것이 우선.
2. **OneDrive 실시간 동기화는 Minecraft 월드 저장 정합성 확보 수단이 아님.** 일부 플러그인은 저장 명령과 별도로 데이터를 기록한다. 다른 쓰기 주체까지 잠시 정지/격리하거나 애플리케이션 일관성 스냅샷이 실제 입증된 뒤만 복구용 P1 백업 인정.
3. **Google Drive G: 볼륨의 Windows 표시 용량·FAT32 표기는 실제 2TB 가입 계정 원격 quota 또는 대형 파일 업로드 제한의 증거가 아님.** 4GiB 초과 단일 아카이브 지원을 미확인으로 다루고, 분할/캐시/전송/복원 검증 없이 한 파일로 백업하지 않는다.
4. P0/P1의 암호화 키·복원 암호를 GitHub, AI 채팅, CMD 인수, 로그, 공개 Drive 링크에 입력하지 않는다. 인증정보가 들어 있는 평문 GSC 백업을 클라우드에 바로 올리지 않는다.
5. **현재 운영 서버를 재시작하거나 백업 생성/삭제하지 않는다.** 운영상 변형이 필요한 시점엔 실제 Windows 호스트 접속·검증 가능한 복구 경로가 있는 상태에서만 진행. 지금 단계는 GitHub/CI 수준의 안전 설계.
6. v3/v4/v5 경로 검사, 8시간 테스트, Native 6/6 검사를 다시 요구하지 않는다. 결과가 바뀐 경우만 범위를 특정하여 새 증거 수집.
