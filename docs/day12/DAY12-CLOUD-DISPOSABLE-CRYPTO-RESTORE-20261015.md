## 실제 CI가 실행해서 확인한 내용

| 항목 | 검증된 범위 |
|---|---|
| AES-256-GCM | OS 난수로 생성한 테스트용 256비트 마스터키에서 목적별 키를 분리하여, 약 64KiB 크기의 시험 청크를 개별 nonce와 인증 추가 데이터(AAD)로 암호화 |
| 암호화된 분할 백업 | 가상의 서버 데이터를 다수의 분할 파일로 기록, 각 암호화 파일 SHA-256 및 원문 SHA-256을 테스트 매니페스트에 기입 |
| 매니페스트 | 키 기반 HMAC 인증으로 매니페스트 변조 거부. 원본 SHA-256·전체 크기·순서·청크 인증정보 재확인 |
| 정상 복원 | 각 암호화 분할 데이터를 복호화해 원본 바이트 단위 일치 확인 |
| 분할 파일 문제 | 암호문 1바이트 변조, 잘림, 누락, 예상 밖 추가 파일 및 잘못된 키 → **거부** |
| 매니페스트 문제 | 매니페스트 임의 수정, 상위 폴더를 가리키는 악성 복원 경로 → **거부** |
| 서버 구조 합성 복원 | 가짜 Wild 월드 region, 가짜 Playground 플러그인 설정, 가짜 Lobby 설정, 가짜 GSC 버전 파일을 tar 형식으로 묶어 암호화 → 복호화 → 별도 임시 디렉터리에 파일 구조 복원 → 파일별 동일성 확인 |
| 구조형 아카이브 방어 | 악성 상대경로(`../`), 절대경로, 심볼릭 링크로 복원 폴더를 벗어나려는 합성 파일 → **거부** |
| 호스트 안전성 | 인자를 전달한 실제 파일 경로/운영 소스를 거부. 모든 입력은 코드 안의 합성 데이터. `os.MkdirTemp`가 만든 일회용 임시 폴더만 사용·청소 |
| 플랫폼 | GitHub Actions **Windows**와 **Linux** 두 작업에서 각각 정상 통과 |

원본 게임 데이터, 서버 월드 또는 설정을 생성·수집하지 않았습니다. 원본 코드에는 `//go:build ignore`가 있어 다른 Go 패키지 빌드에 우발적으로 포함되지 않습니다. 의도적으로 실행할 때도 사용자 입력 경로나 클라우드 계정을 받지 않습니다.

## 이 검증으로 끝났다고 주장하면 안 되는 항목

- **실제 Minecraft Paper World/플러그인/외부 DB/GSC 상태의 정합성 있는 스냅샷**: 미검증. 특히 OneDrive 동기화 경로 안에 현재 서버 원본이 있다는 운영자 확인은 그대로 유지. 실시간 동기화나 단순 폴더 복사가 복구 가능성을 보장하지 않음.
- **Google Drive 2TB / OneDrive 1TB의 실제 계정·잔여 용량·DriveFS 캐시·전송·클라우드 측 존재 여부**: 미검증. Windows에 표시된 G: FAT32/410GB 여유는 실제 Google 클라우드 원격 할당량/최대 단일 파일 크기의 확증이 아님.
- **생산용 암호화 패키지**: 이번 코드는 최소형 **일회용 시험기**. 복구 비밀키를 사용자에게 안전하게 생성·보관·재발급·복원하는 설계, 대용량 디스크 경계, 스트리밍 메모리 제약, 압축·멀티파일 생성 정책, 서명/키 라이프사이클, 권한·로그 유출 감사는 별도 필요. **사용자 실제 파일에 이 코드를 실행하지 말 것.**
- **실제 Google/OneDrive 업로드·다운로드 후 완전 해시 및 GSC/Paper 실행 복원**: 아직 미실행. 라이브 원본 보관/원복/네트워크 절연 테스트 증거 없음.
- **Day12.7·12.11·12.5·12.13 자동 Stable 승인**: 별도 엄격한 릴리즈 게이트를 충족하지 못했으므로 `FINAL-RELEASE-GATES.json`의 거부 유지.

## 현재 실서버 상태와 다음 진입 조건

- 실제 v4 결과에서 서버 경로 3/3 확인, 사용자 확인으로 **서버 원본이 OneDrive 내부**에 있음. 실제 v5 메타데이터 계획에서 Google·OneDrive의 신규 백업 후보와 로컬 스테이징 후보 총 3개는 모두 `PLANNED_NOT_CREATED`; 원본과 실제 후보 중첩 없음/정규화 경로 확인됨. **후보를 생성·업로드하지 않았음**.
- Other는 의도적 **OFFLINE**, 검사 때문에 켜지 않음. 과거 Golden 백업은 디스크 용량 때문에 운영자가 삭제함. **현재 복구본이 존재한다는 증거 없음**.
- 실제 운영 백업 전 필수: **(1) 계정/쿼터·로컬 캐시·소스 총량, (2) 운영 중인 모든 쓰기 주체와 정합성 경계, (3) 비밀키 복구·암호화·분할 아카이브 설계, (4) 업로드 완료 및 다른 위치에서 다운로드·해시 확인, (5) 원본을 덮어쓰지 않는 격리된 복원 검증**.
- 다른 운영 시험은 기존 실서버 8시간 97샘플 범위 PASS, Native Java/RCON 6/6 범위 PASS, GSC4.5.1+Paper26.3 격리 오프라인/강제 종료 복구 PASS 기록을 재사용. 다만 최종 signed Stable은 아직 **BLOCKED**.
