# GeumyiLobby 0.1.1 — Garden Nexus compatible

## Player compass GUI

The lobby grants a **Geumyi server guide compass** on join. Right-click opens a 54-slot, multi-page Bukkit inventory menu:

- Server transfer: Wild, Playground, Other (GSC availability checked before each connection).
- Server guide: each backend's purpose and lobby routing.
- Quick start: compass use, /lobby, last-location restoration.
- Network technology: Velocity, Geyser/Floodgate, GSC, GSCM and backup model (admin-only control is NOT exposed to players).
- Basic etiquette and troubleshooting help.
- Return-to-center and close.

Transfers use the existing GSC `/api/v4/network/server-state` check; a menu item is not an unconditional teleporter. No admin API URL, token, backup or privileged action is included in player-facing GUI.

## Prebuilt world preservation

New world archives can contain `world/geumyi-lobby-prebuilt.marker`. The plugin will **not auto-build the old starter plaza** when this marker is present even if `build-on-start: true`. The prebuilt marker only disables **automatic** reconstruction; `/lobbyadmin rebuild` intentionally still rebuilds the old layout and should **not** be used with Garden Nexus v2.

If running the old plugin against the new map, set `build-on-start: false` before starting. Back up the original world and plugin/config, stop the lobby gracefully, swap, start and conduct live client checks. Roll back both world/plugin on error.

Oak leaves generated by the plugin's legacy builder are now marked persistent to prevent natural leaf decay.

## Existing invariants

- Lobby spawn remains (0.5, 81, 0.5); Adventure/protected status.
- Three gate trigger blocks and Velocity server IDs unchanged.
- Portal movement triggering remains disabled by default in config.
- Existing GSC API loopback-only origin validation retained.
- Separate Java and Bedrock client validation is still required.
