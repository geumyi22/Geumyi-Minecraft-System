금이 서버 Day12 - P0 독립 로컬 암호문 재검사 [READ ONLY]
==============================================================

이 도구는 기존 P0 로컬 암호문을 절대 변경하지 않고 검증합니다.
기존 서버/OneDrive/Google Drive/프로세스를 열거나 변경하지 않습니다.
Google Drive로 백업을 새로 업로드하지도 않습니다.

기존 백업을 만들 때 사용한 복구 암호가 필요합니다.
복구 암호를 채팅, GitHub, 파일, 로그 또는 사진으로 공유하지 마세요.

실행:
  1. 승인된 검증 ZIP을 압축 해제(기존 암호화 도구와 별개).
  2. RUN_Day12_P0_Offline_Verify_READ_ONLY.cmd 더블 클릭.
  3. 기존 백업 생성 당시의 복구 암호를 화면에 표시하지 않고 입력.
  4. "P0_OFFLINE_VERIFY_PASS" 또는 "P0_OFFLINE_VERIFY_BLOCKED" 범주만 공유.

검증 범위:
- LOCALAPPDATA/Geumyi-P0-Encrypted-Staging/ 아래에서
  완료 표시가 있는 가장 최근 P0 암호화 폴더를 자동 선택.
- 미리 정해진 20개 설정 파일의 모든 AES-256-GCM 인증 태그,
  원문 SHA-256 및 크기, AEAD AAD의 경로/순서, 암호화 매니페스트,
  세 Velocity/Floodgate 키의 복호된 바이트 동등성을 확인.
- 복원한 평문은 메모리에서만 확인하고 디스크에 쓰지 않음.
- 디렉터리의 예상치 못한 파일/심볼릭 링크/추가 청크를 차단.
- 잘못된 암호나 손상된 암호문을 차단. 불필요하게 재시도하지 마세요.
- 정상 완료 상태 외 P0 구름 업로드·클라우드 재다운로드·월드/플러그인
  전체 복원·실제 GSC/Paper 재기동·업데이트 안전성은 입증하지 않음.

보관:
기존 백업 폴더와 암호는 절대 삭제하지 마세요.
추후 독립 복구용 Google Drive 업로드는 별도 작업입니다.
이 단계에서 직접 클라우드로 암호문을 올릴 필요는 없습니다.

이 도구의 Windows/Linux CI 통과는 서버에서의 PASS와 다릅니다.
실제 Windows 서버 PC 실행 후 PASS 줄만 공유해 주세요.
