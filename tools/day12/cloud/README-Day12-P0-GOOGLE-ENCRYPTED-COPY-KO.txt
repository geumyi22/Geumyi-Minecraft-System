금이 서버 Day12 P0 — Google Drive 미러링(C:) 전용 암호문 복사 도구 v2
========================================================

이미 서버 PC에서 확인한 설정:
Google Drive for desktop의 내 드라이브 = 파일 미러링.
G: 루트의 '내 드라이브' 바로 가기 대상은 C: 사용자 프로필의 '내 드라이브'.

실행: RUN_Day12_P0_Google_Encrypted_Copy.cmd

1. Google Drive for desktop에서 의도한 Google 계정이 로그인됐는지 확인.
2. 탐색기에서 G:의 '내 드라이브' 바로 가기 대상 C: 경로를 확인.
3. CMD 프롬프트에 확인된 C: 미러링 폴더의 전체 경로를 입력.
4. 프로그램은 G:의 .lnk 바로 가기의 TargetPath를 읽어 입력한 C: 경로와
   완전히 동일한지 검사한다. 다른 C: 폴더나 일반 폴더는 실패 처리.
5. 프로그램이 GOOGLE_P0_ENCRYPTED_UPLOAD_APPROVED를 요청할 때만 정확히 입력.
6. 성공 시 P0_GOOGLE_MIRROR_COPY_HASH_VERIFIED=23 및
   P0_GOOGLE_MIRROR_COPY_COMPLETE=true 두 줄 모두 확인.

기존 로컬 P0 복구본에는 AES-256-GCM 독립 검증을 통과한
20개 암호문과 헤더·암호화 매니페스트·완료 마커, 총 23개가 있음.
이 도구는 확인된 81,413바이트를 별도 신규 미러링 하위 폴더에
복사하고 각 항목의 원본 전후/복사본 SHA256 일치를 검사한다.
덮어쓰기/자동 삭제 없음. 기존 서버 GSC/Paper/Velocity/OneDrive에 접근하지 않음.
복구 암호를 물어보거나 비밀값을 출력/업로드하지 않음.

중요:
미러링 폴더의 SHA256 일치 = 클라이언트 로컬 파일 복사 확인.
Google 서버 원격 업로드 완료나 원격 저장본 독립 다운로드 증거 아님.
Google Drive 웹에서 새 폴더 존재를 확인하고, 별도 다운로드한 사본을
격리된 로컬 환경에서 검증해야 원격 복구까지 확인할 수 있음.
Google Drive 동기화 설정을 변경하지 마세요.
파일 오류 시 부분 새 폴더가 남을 수 있음; 임의 삭제 또는 중복 재시도 금지.
결과는 P0_ 상태 줄만 공유. 암호·실제 설정·백업 파일 업로드 금지.
기존 오동작 v1.1 도구는 다시 실행하지 마세요.
